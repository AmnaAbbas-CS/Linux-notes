# Command Reference

| Command | What it does | Where I used it |
|---|---|---|
| `pwd` | Shows my current location | Episode 1 |
| `ls` | Lists files and folders | Episode 1 |
| `cd folder` | Moves into a folder | Episode 1 |
| `cd ..` | Moves up one folder | Episode 1 |
| `cd ~` | Goes to my home folder | Episode 1 |
| `cat file` | Shows a file's contents | Episode 2 |
| `mkdir name` | Creates a folder | Episode 2 |
| `cp file new` | Copies a file | Episode 2 |
| `cp -r folder new` | Copies a folder and its contents | Episode 2 |
| `rm file` | Deletes a file permanently | Episode 2 |
| `sudo` | Runs a command as administrator | Episode 2 |
| `which cmd` | Shows where a command lives | Episode 2 |
| `ls -l` | Lists files with owner and permissions | Episode 2 |
| `ls -ld folder` | Shows a folder's own owner and permissions | Episode 2 |
| `alias name='cmd'` | Creates a shortcut name for a command | Episode 2 |
| `chmod +x file` | Makes a file runnable | Episode 2 |
| `readlink -f file` | Shows where a shortcut finally leads | Episode 2 |
| `echo $PATH` | Shows folders searched for commands | Episode 2 |
| `id` | Shows my user and groups | Episode 2 |
| `ip a` | Shows network interfaces and IP address | Episode 2 |
| `hostname -I` | Prints just my IP address | Episode 2 |
